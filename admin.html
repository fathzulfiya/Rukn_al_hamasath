Photo manager

Add, reorder and remove product photos. No file names to type.

Start here (one time each visit)
  1. Click Choose my site folder below.
  2. Select the folder that contains index.html (your site folder), then click View files and Allow when the browser asks to save changes.
  3. Then use + Add photos under any product.

This page needs Google Chrome or Microsoft Edge on a computer. Please open it there.

Ready.

The first photo of each product is the one shown on the shop. The other photos show as thumbnails on the product page (up to 6). Use ◀ ▶ to change the order. ✕ removes a photo from the product (the file stays in your folder). After any change, refresh your website with Ctrl + F5.
